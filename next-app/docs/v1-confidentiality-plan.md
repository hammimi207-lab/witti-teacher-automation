# 기록 요정 V1 — 회원가입 전 비밀유지 동의 설계 초안

상태: 검토용. 아직 서비스에 적용하거나 재배포하지 않았음.

## 이용 흐름

1. 모든 일반 방문자를 시험 이용 안내로 이동한다. 기존 회원에게도 동일하게 적용한다.
2. 운영자가 초대한 교사인지 확인하고 이메일 인증을 완료한다.
3. 비밀유지 약정과 개인정보 수집·이용 안내를 각각 읽고 별도 체크박스로 동의한다. 기본 체크는 하지 않는다.
4. 서버가 동의 증빙 저장을 완료한 경우에만 서명된 HttpOnly 쿠키를 발급한다. 저장 실패 시 이용 권한을 부여하지 않는다.
5. 동의 후 회원가입 또는 로그인을 진행한다. 검증한 이메일과 가입 계정이 일치할 때만 기록을 연결한다.
6. 약정 버전이 바뀌거나 이용 기간이 끝나면 재동의를 요구한다. 과거 동의서는 덮어쓰지 않는다.

## 별도 동의 기록

- 고유 동의 번호, 무작위 방문자 식별자
- 성명, 검증한 이메일, 소속 어린이집
- 이메일 검증 시각, 서버에서 생성한 동의 시각(UTC)
- V1 식별 정보, 비밀유지 및 개인정보 안내 버전, 당시 전문과 해시
- 각각의 명시적 동의 여부, 보관 만료 시각
- 가입 후 연결된 회원 ID와 연결 시각(회원가입 전에는 비어 있음)

이름 입력과 이메일 인증만으로 법적 실명 인증이 이루어진다고 표현하지 않는다.
IP나 기기 지문은 기본 수집하지 않는다. 사용하지 않은 방문자의 단순 접속을 동의로 기록하지 않는다.

## 접근 및 관리

일반 화면과 기능 API 모두 서버에서 동의 및 초대 권한을 확인한다. 팝업이나 브라우저 저장소 값만으로 허용하지 않는다.
동의 안내 화면에는 내부 공지, 기능 설명, 시험 자료를 노출하지 않는다.
관리자는 별도 인증된 관리 화면에서 동의자·시각·버전·회원 연결 상태를 조회하고 증빙을 내보낸다.
익명·일반 회원의 동의 목록 조회, 증빙 변조, 타인 기록 연결을 차단한다.
만료 자료 삭제 일정과 실패 알림을 보관기간에 맞춰 구성한다.

## 비밀유지 약정 문안 초안 — 운영자 확인 및 전문가 검토 필요

기록 요정 V1은 지정 교사를 대상으로 하는 비공개 시험 서비스입니다.
참여자는 시험 과정에서 제공받은 비공개 화면, 설명 자료, 기능 구성 및 운영자가 비밀로 표시한 정보를 시험과 피드백 목적에만 사용합니다.
운영자의 사전 서면 동의 없이 해당 자료나 접근 권한을 제3자에게 전달하거나 화면·영상·설명 자료를 외부에 게시하지 않습니다.
이미 적법하게 공개된 정보, 참여자가 독자적으로 개발한 정보, 비밀유지 의무 없이 적법하게 취득한 정보는 제외합니다.
법령에 따른 신고·제출 또는 적법한 권리 행사를 제한하지 않습니다.
시험 종료 시 제공 자료의 반환·삭제 요청에 협조하되 법령상 보관 의무가 있는 자료는 제외합니다.
이 약정은 교사가 작성한 기록의 소유권 이전이나 무제한 책임·일괄적인 위약금 동의를 뜻하지 않습니다.
비밀유지 의무 기간과 운영자의 정확한 명칭은 확정 후 표시합니다.

## 개인정보 안내에 반드시 확정할 사항

운영자 이름, 문의 이메일, 수집 목적과 항목, 보관기간 및 파기 방식, 동의 거부권과 시험 이용 제한을 명시한다.
개인정보 보관기간과 비밀유지 의무 기간은 구별한다.

## 검증 기준

- 미동의 방문자와 기존 회원 모두 기능 화면 및 API 접근 불가
- 체크박스 미선택, 위조·만료 쿠키, 구버전 동의로 접근 불가
- 데이터 저장 실패 시 쿠키와 이용 권한 발급 불가
- 인증한 이메일과 다른 회원 계정에 자동 연결 불가
- 관리자 외 증빙 조회 불가 및 동의 원문 보존
- 동의 후 정상 회원가입·로그인·기록 이용 가능

## 출원 관련 한계

이 절차는 향후 시험 이용을 관리하기 위한 조치이다. 과거 공개를 소급해서 비공개로 만들거나 특허 가능성을 보장하지 않는다.
V1 최초 배포 및 공유 내역은 보존하고 출원 대리인에게 전달한다.
