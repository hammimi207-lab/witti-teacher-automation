# 놀이 참고문헌 더보기

6단계는 ‘참고문헌 더보기’다. 공개 Crossref REST API를 서버에서 호출해 실제 등록된 학술 자료를 표시한다. API 키나 추가 AI 호출은 필요 없다. https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/ 및 https://github.com/CrossRef/rest-api-doc 를 확인했다.

확인 관찰에서 블록·물·모래·음악·미술·역할·자연·움직임 놀이 키워드만 로컬에서 골라 영어 검색어를 제안한다. 사진·관찰 원문·아동 별칭은 학술 API로 전송하지 않는다. 교사는 주제 검색어를 수정할 수 있다. 서버는 로그인과 동일 출처를 확인하고 고정된 Crossref endpoint에만 질의한다. 시간 제한 15초, 오류·재시도·빈 결과 상태를 제공한다. 단계 이동 중 결과와 검색어는 유지하며, 검색 실패가 분석·기록을 막지 않는다.

Crossref가 반환한 DOI·제목·저자·연도·학술지/자료 유형과 등록 초록의 일부를 그대로 표시한다. 영유아 관련 표현과 첫 주제 검색어가 제목·초록에서 확인된 자료만 후보로 남기고, DOI 중복·잘못된 형식·정정문은 제외한다. DOI 링크는 실제 조회 결과에서만 만든다. 결과는 연구의 품질·현재 놀이 효과를 보증하는 추천이 아닌 참고 후보다.

원문은 자동으로 열람하지 않는다. ‘서지 정보만 확인’ 또는 ‘등록 초록 일부 확인’과 ‘원문 미열람’을 명시한다. 연구 대상 연령, 만 2세 직접 근거, 핵심 결과·연구 한계가 검증됐다고 요약하지 않으며 해당 항목은 원문 확인이 필요하다고 표시한다. 초록이 없는 자료의 내용을 생성하지 않는다. 원문 링크는 DOI의 출판사 페이지이며 유료이거나 로그인이 필요할 수 있다. 한국 기관 보고서 전체 검색 및 원문 기반 한국어 연구 요약은 이번 구현 범위에 없다.

검증: 실제 Crossref 검색에서 블록·음악 놀이 자료 반환 확인. 오프라인 서버 테스트로 인증·출처·고정 검색 URL·등록 메타데이터 정규화·불일치 제외·외부 실패 확인. 실제 클라이언트 Edge 테스트로 검색 실패/재시도·결과 및 원문 링크·초록 확인 범위·단계 이동 후 결과 보존 확인. TypeScript·변경 소스 ESLint와 운영 빌드 검증.
