# 회원별 퀵메뉴

기록요정 v2 홈을 회원 여부에 따라 구분한다.

- 비회원: 관찰 녹음 / 사진 선별 / 새 기록 생성. 새 기록은 기존 비회원 작성 경로로 열린다. 관찰 녹음은 기기에서 재생·내려받을 수 있다.
- 회원: 처음에는 네 칸 모두 `+`. 눌러 기능을 선택하면 그 칸에 추가한다. 각 칸의 변경 버튼으로 교체하거나 비울 수 있다.
- 목록 안내: “기록 요정의 다양한 기능들 중 원하는 기능을 추가해서 사용해 보세요!”
- 선택 기능: 관찰 녹음 / 녹음 파일 분석 / 놀이 영상 분석 / 사진 선별 / 새 기록 생성 / 내 기록 보기. 각 기능의 한 문장 설명을 함께 보여 준다. 중복 선택은 막고 다른 칸에 추가한 기능을 표시한다.

선택은 Supabase Auth 회원의 `user_metadata.girok_quick_menu`에 저장한다. 다음 접속과 다른 기기에서도 로그인한 회원의 설정을 읽는다. 저장 실패 시 이전 설정으로 되돌리고 안내한다. 테이블 마이그레이션은 필요 없다. 이 필드는 권한 판단에 사용하지 않는다.

관찰 녹음은 기존 마이크 녹음·회원 전사·놀이 연결을 유지한다. 녹음 파일 분석은 저장한 MP3/M4A/WAV/WebM/Ogg 파일(4MB 이하)을 전사하고 수정문을 새 기록에 연결한다. 놀이 영상 분석은 별도의 창에서 기존 영상 분석(90초·3MB 이하)을 수행한다. 관찰 녹음 창에는 영상 업로드를 넣지 않는다.

주요 파일: `features/home/quick-action-grid.tsx`, `quick-menu.ts`, `audio-file-analysis.tsx`, `app/api/account/quick-menu/route.ts`, `app/api/observations/audio-file/route.ts`, `app/page.tsx`.

검증: 회원/동의/입력 검증과 저장 실패·설정 정규화 API 테스트, 390px 실제 홈 컴포넌트 브라우저 테스트(비회원 3메뉴, 회원 4칸, 6개 목록, 설정 저장·다시 접속·교체·비우기·오류 복원, 파일 전사와 분리된 창), 타입·린트·프로덕션 빌드 통과. 실제 회원 설정 변경과 실제 유료 AI 호출은 대역으로 대체했다.
