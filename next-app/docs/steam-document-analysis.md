# STEAM 다운로드 분석

STEAM Word 다운로드는 인증된 사용자의 저장 기록에서 STEAM 메타데이터를 다시 읽는다. 브라우저가 보낸 분석·관찰은 사용하지 않는다. 기존 기록도 다시 분석하지 않고 새 다운로드 구성을 적용한다.

문서에는 사진별 STEAM 영역, 구체적인 사진·관찰 근거, 잠정적 해석, 교사의 선택 여부, 추가 관찰, 미실행 놀이 제안을 구분하여 담는다. 확인된 관찰·교사 해석·지원 계획·과정 초안과 놀이 이야기를 보존한다.

교육과정 연결은 교사가 확인하고 저장한 관찰의 구체적인 표현과 내용범주를 연결하는 규칙 기반 후보다. 생성된 이야기, 교사 해석, 미래 계획을 사실 근거로 사용하지 않는다. STEAM 영역에서 교육과정 영역을 일대일로 추정하지 않는다. 관련 표현을 찾지 못하면 추가 관찰 필요를 표시한다. 의미 전체를 이해하는 별도 AI 분석은 아니며, 교사 검토가 필요하다. 새로운 AI 호출이나 추가 개인정보 전송은 없다.

0~1세·2세는 2024 개정 표준보육과정, 3~5세는 2019 개정 누리과정을 사용한다. 내용범주는 2026년 10월 5일 확인한 공식 고시·해설서에 근거한다. 설명은 공식 문구를 인용한 것이 아닌 관찰 해석이며 연령별 성취 판정이 아니다. 자료 링크를 문서에 함께 담는다.

- 표준보육과정 고시 https://i-nuri.go.kr/teacher/board/view.do?board_idx=4332&data_type=normal&manage_idx=137&menu_idx=20
- 누리과정 해설서 https://repo.kicce.re.kr/handle/2019.oak/4997

저장된 사진 순서를 보존하고 삭제된 사진의 번호를 다른 사진에 재사용하지 않는다. 삭제된 사진은 문서에서 제외하되 당시 저장한 관찰 텍스트는 보존한다. 다운로드는 기록 데이터와 원본 문서를 수정하지 않는다.
