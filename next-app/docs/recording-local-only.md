# 관찰 녹음: 파일은 기기에, 서버는 실행 이력만

관찰 녹음 창에서 직접 녹음과 기존 녹음 파일 업로드를 제공한다. 원본 음성과 전사문은 열린 창의 메모리에만 유지한다. 저장은 기기 파일 내려받기로 제공하며, 음성 전사는 기존 인증·동의가 적용된 `/api/observations/audio-file`을 통해 서버 메모리에서 처리한다. 전사문은 AI 학습용 기록 조각이나 서버 전사 테이블에 자동 저장하지 않는다.

`/api/observations/recording-history`에는 실행 ID·일시·본인 소유 놀이의 연결만 남긴다. 기존 `record_fragments`에는 `recording_execution_only` 태그와 빈 `raw_text`를 사용하며 `record_audio`, `record_transcriptions`, Storage에는 새 데이터를 쓰지 않는다. 이력 목록에는 일시·놀이명만 표시하고 이전 원본/전사문을 노출하지 않는다. 기존 보관 데이터의 일괄 삭제는 수행하지 않는다.

닫기 버튼 및 Escape 전에 “따로 저장하지 않은 녹음 파일은 저장되지 않습니다”와 기기 저장 후 추후 STEAM 활용 가능 안내를 확인한다. 닫으면 임시 음성과 전사문을 지운다. 교사가 직접 전사문을 STEAM 관찰에 추가한 경우에만 해당 관찰 작업과 저장 기록에 내용이 포함된다.

녹음 파일은 Vercel 요청 제한에 맞춰 4MB 이하이며 MP3·M4A·WAV·WEBM·OGG·MP4를 지원한다. 실행 이력 생성 실패·전사 실패는 파일을 유지하고 오류를 안내한다. 실제 아동 음성이나 유료 전사 호출 없이 오프라인 브라우저와 서버 fixtures로 검증한다.
