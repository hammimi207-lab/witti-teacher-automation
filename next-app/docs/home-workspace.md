# 작업 중심 홈 개편

## 변경 범위

- `src/app/page.tsx`: 긴 소개, 중복 실행 버튼, 홍보 카드, 내부 운영 문구를 제거하고 소개와 네 작업 카드로 구성.
- `src/app/globals.css`: 홈·수집 모달 스타일, 모바일 헤더 간격, 터치 영역과 포커스 표시 추가.
- `src/features/home/`: HomeHero, QuickActionGrid, QuickActionCard, CaptureDialog, ObservationRecorder, PhotoSelector, HomeActivitySummary 추가.
- `tests/home-browser.cjs`: 실제 컴포넌트와 스타일을 사용하는 격리된 브라우저 테스트.

## 버튼 동작

| 버튼 | 실제 동작 |
| --- | --- |
| 관찰 녹음 | 홈에서 모달과 마이크 권한 요청을 열고 녹음 시작. 기존 작업이 있으면 작업을 다시 열기. 중지·재생·개별 음성 다운로드·메모 작성/다운로드 지원. |
| 사진 선별 | 홈 클릭 시 다중 파일 선택. 미리보기, 수동 선택, 전체 선택/해제, 개별 원본 다운로드, 목록 제거 지원. |
| 새 기록 생성 | 기존 `/records/new`로 이동. 기존 로그인 복귀 목적지와 작성 기능 재사용. |
| 내 기록 보기 | 기존 `/records`로 이동. 목록·수정·삭제·보관 정책 재사용. |

로그인·회원가입·프로필·로그아웃의 기존 코드, 인증/동의 처리, DB와 저장 API는 이 작업에서 변경하지 않았다. 사진 선별은 로컬 기능이며, 녹음 전사는 기존 홈의 동의 정책 안에서 실행된다. 초기 홈에는 새 라우트나 패키지를 추가하지 않았다. 이후 자동 전사 API를 추가했다.

## 저장 범위와 준비 중인 기능

새 녹음·전사문·메모·사진 선택은 **현재 홈 화면이 유지되는 동안만** 보관된다. 모달을 닫았다 열어도 유지되지만 페이지 이동/새로고침 후 복원하는 자동 저장은 아직 없다. 음성·메모를 먼저 다운로드하도록 화면에 안내하며 전체 페이지 이탈 시 브라우저 경고를 등록한다. 브라우저나 모바일 OS 종료 시 이 경고가 보장되지는 않는다. 기존 기록 작성기의 임시 저장은 그대로다.

사진 원본은 수정하거나 서버에 업로드하지 않는다. 기존 60장/개별 20MB/전체 100MB 제한을 제거했다. 원본 File 참조를 유지하고 한 장씩 디코딩하여 긴 변 256px의 JPEG 미리보기와 작은 색감·구도 특징값을 만든다. 디코딩 결과와 임시 원본 URL은 즉시 해제하고, 전체 원본을 Base64로 복제하거나 Supabase·IndexedDB·localStorage에 저장하지 않는다. 실제 한계는 기기 메모리와 브라우저 지원에 따른다. HEIC는 브라우저가 지원하면 열고, 지원하지 않으면 JPG 변환 안내를 표시한다. 진행률은 업로드가 아닌 기기 내 정리 진행률이다.

`photo-analysis.ts`가 화면 영역별 색상, 색상 분포, 밝기 변화 패턴을 비교해 비슷한 사진을 묶는다. 얼굴 인식이나 의미 기반 AI 분류가 아니므로 교사가 직접 비교해야 한다. `photo-gallery.tsx`는 겹쳐진 사진 묶음, 전체 사진, 선택한 사진 보기를 제공하며 한 번에 60개 항목만 표시하고 더 보기로 확장한다. 이 표시 단위는 사진 입력 수 제한과 다르다. 정리 중 일시 정지/계속, 목록 비우기, 개별 제거를 지원한다. 선별할 장 수는 60장 상한 없는 숫자 입력으로 변경했다.

선택한 사진 다운로드는 미리보기가 아닌 원본 File을 사용한다. 표시하는 미리보기 파일 용량은 압축 파일의 합계이며, 브라우저 전체 메모리 사용량을 뜻하지 않는다.

녹음은 HTTPS 또는 localhost의 MediaRecorder 지원 브라우저에서 실행된다. 권한 거부·마이크 없음·장치 사용 불가·녹음 오류를 구분하고, 취소 후 늦게 반환된 마이크 스트림도 해제한다. 한 번에 최대 10분 녹음하며 모달을 닫으면 녹음을 마친다.

아이 후보 추출, 사진 얼굴별 분류·품질 분석·용도 추천, 관찰-사진 자동 연결, 묶음 ZIP 다운로드와 서버 보관은 미구현이다. 가짜 결과나 통계는 없다. 녹음 시작 시각과 원본 File의 수정 시각은 별개이며, 파일 수정 시각을 촬영 시각으로 표시하지 않는다.

## 검증

- `npm run lint`: 통과.
- `npx tsc --noEmit`: 통과.
- `npm run build`: 통과.
- `node --test tests/login.test.mjs tests/confidentiality.test.mjs tests/record-saving.test.mjs tests/photos.test.mjs tests/writing-reset.test.mjs`: 33개 통과.
- `node tests/home-browser.cjs`: Edge에서 통과. 설치된 Playwright 경로는 `PLAYWRIGHT_MODULE`, 브라우저 채널은 `BROWSER_CHANNEL` 환경변수로 지정 가능.
- 320/360/390px 모바일과 1280px 데스크톱에서 2×2 카드, 첫 화면 노출, 가로 넘침 없음 확인.
- 다중 사진 선택, 잘못된 형식·손상 파일 처리, 선택·다운로드·모달 재열기 확인.
- 가상 마이크를 사용한 실제 MediaRecorder 녹음 및 비어 있지 않은 음성 다운로드 확인. 메모 원문과 다운로드 내용 일치 확인.
- 권한 거부 후 재시도, 권한 요청 취소 후 스트림 해제, Escape와 키보드 포커스 확인.
- 추가 사진 검증: 125장(22MB 파일 5개 포함, 총 110MB 초과)의 입력, 실제 색감/구도로 2개 묶음 분류, 256px 미리보기, 60개씩 표시, 원본 다운로드 바이트 일치, 외부 네트워크 전송 없음 확인. 합성 테스트 사진으로 검증했으며 현장 사진의 분류 정확도 평가를 대신하지 않는다.
- `node --test tests/photo-analysis.test.cjs`: 유사한 장면/작은 밝기·구도 변화와 다른 장면을 비교하는 단위 테스트 2개 통과.

구현 참고: [createImageBitmap](https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap), [canvas.toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob).

브라우저 검증은 실제 홈 컴포넌트·CSS·기존 헤더를 사용하는 **동의 완료/비로그인/공지 없는 격리 환경**이다. 실계정 로그인, 실제 휴대폰 마이크, 모바일 Safari와 서버 업로드 E2E를 수행했다는 의미는 아니다. 스크린샷과 결과는 프로젝트 루트의 `outputs/home-check/`에 있다. 운영 배포는 수행하지 않았다.


## 자동 전사 추가

녹음 종료 시 `/api/observations/transcribe`로 음성을 전달하고, 기존 OpenAI 키와 `gpt-4o-mini-transcribe`로 한국어 전사를 수행한다. 결과는 해당 오디오 바로 아래 표시한다. 녹음과 메모를 보존하며 진행 상태, 빈 전사문, 오류 및 전사 재시도, 전사문 TXT 다운로드를 지원한다.

음성은 서버 메모리를 거쳐 OpenAI로 전달되지만 Supabase·파일 시스템·앱 로그에 저장하지 않는다. 기존 proxy 동의 정책을 그대로 적용하고 API에서 같은 출처, 파일 형식, 크기를 검사한다. 배포 환경을 고려해 요청 음성을 4MB 이하로 제한한다. 브라우저에 32kbps 녹음을 요청하고 3.7MB에서 자동으로 중지한다. 전사 서버의 타임아웃은 100초, 클라이언트는 110초다. 삭제·페이지 이탈 시 진행 중인 요청을 취소한다.

검증: API 단위 테스트 2개, 브라우저의 자동 전사·진행/성공 표시·오류 후 재시도·전사문 다운로드·오디오 바로 아래 배치, 변경 파일 lint, 타입 검사와 빌드 통과. 실제 키로 합성 한국어 음성을 전사하여 문장 반환을 확인했다. 전체 lint는 별도로 변경 중인 `.qa/check-weekly-and-photos.cjs`와 `use-writing-draft.ts` 등의 오류가 있어 변경 파일 검사와 구분했다.

참고: [OpenAI 음성 전사 공식 문서](https://developers.openai.com/api/docs/guides/speech-to-text).
