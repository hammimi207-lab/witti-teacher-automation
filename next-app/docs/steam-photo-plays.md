# 사진마다 다른 놀이 관찰과 쉬운 STEAM 읽기

관찰 더하기는 선택한 사진 1~5장 각각에 아이의 말·행동·놀이 흐름 입력을 제공한다. 사진 보관 ID/업로드 파일의 안정 키로 입력을 연결하므로 사진을 해제하거나 다시 선택해도 같은 사진의 메모를 유지한다. 분석에는 현재 선택한 사진의 관찰만 포함한다. 각 사진 버튼의 녹음 전사문은 해당 사진 놀이 흐름에만 추가한다. 공통 메모는 별도 기록용이며 사진별 분석 근거로 사용하지 않는다.

분석 프롬프트/출력은 사진 번호마다 별개의 놀이 객체를 요구한다. 사진 수와 결과 수/번호가 맞지 않으면 실패 상태로 돌려 입력을 유지한다. 각 놀이의 사진 근거는 해당 사진에만, 말·행동 근거는 해당 사진에 입력한 관찰에만 역검증한다. 다른 사진 인용은 제외한다. 각 놀이에 해당하는 STEAM 영역만 표시하며, 모든 영역을 채우지 않는다.

UI에는 사진별 미리보기·‘다른 사진과 별개’ 제목·영역 카드·놀이 지원을 각각 표시한다. 근거가 없는 사진은 추가 관찰 필요로 안내한다. 해석 선택은 사진번호+영역 키를 사용해 같은 영역이 다른 사진에서 나와도 독립적으로 선택한다. 사진별 관찰, 카드 수정, 선택 정보는 임시 복원/서버 저장/다시 열기에 보존한다. 사진 저장 후 파일 키를 보관 ID로 옮겨 관찰 연결을 유지한다. 기록/이야기에서는 사진별 관찰 표지를 보존하며 서로 다른 사진을 한 아이의 연속된 시도로 연결하지 않도록 프롬프트를 제한한다.

T 기술은 ‘도구를 써 보는 놀이 / 어떤 도구를 어떻게 써 보았나요?’, E 공학은 ‘놓고 이어 만드는 놀이 / 어떻게 놓거나 이어서 만들어 보았나요?’로 설명한다. 숟가락·집게, 블록 길·놓는 자리 바꾸기 등 설명 예시와 실제 확인된 관찰을 구분한다. 카드 항목은 ‘사진·관찰에서 본 모습 → 이 행동에서 배울 수 있는 것 → 다음에 눈여겨볼 행동 → 지금 놀이에서 이어 해볼 지원’이다. 어려운 용어를 쓰지 않고 일상적인 행동 중심으로 응답하도록 서버 프롬프트를 수정했다.

이전 저장 기록은 읽을 수 있다. 이전 분석에는 사진별 그룹이 없으므로 이를 명시하고 재분석 시 새 방식을 적용한다. 공통 메모만 있는 이전 작업은 각 사진 관찰을 보충해야 해당 텍스트를 사진별 근거로 사용한다. 학술 검색 및 기존 인증/사진 소유권/교사 확인/기록 저장 정책은 유지한다.

검증: 다섯 사진의 독립 관찰과 교차 근거 제외, 결과 번호/개수 검사, 1~5 사진별 입력 필드, 선택 해제한 사진 관찰 제외, 해당 사진 녹음 연결, 다른 사진 해석 독립 선택, 카드 수정/재분석 보존, 업로드 후 관찰 매핑, 저장 후 사진별 관찰 재열기. 실제 아동 사진/유료 AI 호출은 하지 않고 오프라인 fixture로 검증한다.
